# Contracts

Service agreements, NDAs, and legal documents.

## Structure

| Document | Purpose | Status |
|----------|---------|--------|
| [[Documents/Contracts/Service-Agreement]] | Master terms for all projects | Template |
| [[Documents/Contracts/NDA]] | Confidentiality agreement | Template |
| [[Documents/Contracts/SOW-Template]] | Statement of work per project | Template |

## Contract Flow

```
Proposal Accepted → Service Agreement Signed → Project Begins → SOW per Project
```

## Usage

1. **Service Agreement** — Signed once per client, governs all future projects
2. **NDA** — Signed when sensitive information needs protection
3. **SOW** — Created per project, references the master Service Agreement
