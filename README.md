# Owen Digitals — Portfolio

My personal portfolio and blog.

**Live:** [owendigitals.work](https://www.owendigitals.work)

## Features

- 🎬 GSAP + Lenis scroll animations
- ✍️ Blog with an authenticated admin (NextAuth)
- 🖼️ Image hosting on Vercel Blob
- 📈 Vercel Analytics

## Stack

Next.js · React · MongoDB (Mongoose) · GSAP · Tailwind CSS

## Running locally

```bash
npm install
npm run dev
```
